# qqbot

本地运行的私人 QQ 群机器人。LLOneBot 提供 OneBot V11 协议接口，
NoneBot2 使用 FastAPI 驱动并负责上层逻辑。

## 项目结构

- `pyproject.toml`：Python 3.12、NoneBot2、FastAPI 驱动和 OneBot V11
  适配器的项目配置。
- `.env`：本地运行配置与密钥，不提交到 Git。
- `.env.example`：需要手工填写的配置项模板。
- `.env.prod`：nb-cli 生成的生产环境驱动配置。
- `qqbot/plugins/llm_chat/`：受群白名单和 @ 触发限制的 DeepSeek 聊天插件。
- `tests/`：不访问外部服务的单元测试。

## 本地运行

```powershell
conda activate qqbot
python -m pip install -e .
nb run
```

首次启动前请填写 `.env`。`SUPERUSERS` 可填写为 QQ 号组成的 JSON 数组，
例如 `["123456789"]`。

如需联网搜索和新闻正文摘要，还需要申请 Tavily API Key，并在 `.env` 中填写
`TAVILY_API_KEY`。没有填写时，天气、榜单、提醒、B站解析和群聊总结仍可使用。

NoneBot 默认监听 `127.0.0.1:8080`。如需调整监听地址或端口，可在
`.env` 中添加 `HOST` 和 `PORT`。

## 连接 LLOneBot

1. 先启动 NoneBot。
2. 在 LLOneBot 的 OneBot 11 配置中启用反向 WebSocket。
3. 将反向 WebSocket 地址设置为
   `ws://127.0.0.1:8080/onebot/v11/ws`。
4. 保存配置并确认 LLOneBot 已连接；随后 QQ 事件会由 LLOneBot 推送给
   NoneBot。

如果启用访问令牌，请在 LLOneBot 与 NoneBot 两端配置相同的 token。

## LLM 聊天

聊天插件仅在以下群中被 `@` 时响应：

- `577015417`
- `482997153`

同一群中，每个统一身份拥有独立的短期上下文；同一真人绑定的多个 QQ 共享该上下文，
其他群友的对话不会自动混入。消息中的 OneBot `@` 段会按 QQ 号解析为明确的被提及
对象，两个群之间也相互隔离。LLM 聊天上下文保存在内存中并在重启后自动清空；用于
群聊总结的普通消息另行保存在本机数据库。默认每个统一身份保留最近 3 轮用户消息，
其中仅保留最近 1 轮 BOT 回复用于衔接对话。历史 BOT 回复不作为人物事实或群内关系
的证据。模型使用 `deepseek-v4-pro` 非思考模式，
每个用户 3 秒内最多发起一次请求，同一群的请求按顺序处理。

高置信的人设覆盖和提示注入会在调用模型前被拦截，也不会进入短期上下文。
系统提示同时要求模型把用户消息、历史记录和长期记忆视为数据，不能用它们覆盖机器人
身份、输出格式或安全边界。普通的一次性创作请求不受影响。

群内命令：

- `/清空对话`：删除自己所有已绑定 QQ 在本群短期上下文中的互动。
- `/清空本群对话`：仅超级用户可用，只清空本群全部 LLM 短期上下文。
- `/清空群聊记录 确认`：仅超级用户可用，只删除本群用于总结的持久消息记录。

上下文长度可以通过环境变量调整：

- `LLM_CONTEXT_TURNS`：每个统一身份保留的用户消息轮数，默认 `3`。
- `LLM_ASSISTANT_CONTEXT_TURNS`：保留的历史 BOT 回复轮数，默认 `1`；设为
  `0` 可完全不向模型提供旧 BOT 回复。

机器人不会执行踢人、禁言等群管理操作，因此在两个群中的权限差异不会影响聊天功能。

## 统一命令

群内发送 `/菜单` 或 `@机器人 菜单` 可以查看相同的固定纯文本菜单。日常使用以
`@机器人 功能名 参数` 为主；机器人先按第一个空白分隔词精确匹配功能名，命中后
直接执行，不经过模型判断。例如 `@机器人 天气 北京`、`@机器人 提醒 30分钟后
关火`。下面的 `/` 命令提供同样的确定性快捷入口：

- `/天气 城市`
- `/运势 [今日|本周|本月|平均]`
- `/新闻 [60秒|知乎|微博]`
- `/新闻详情 [知乎|微博] 序号`
- `/搜索 关键词`
- `/历史上的今天`
- `/提醒 30分钟后 关火`
- `/提醒 明天 20:00 开黑`
- `/提醒列表`
- `/取消提醒 编号`
- `/总结 [消息条数]`
- `/清空对话`
- `/我的记忆`
- `/忘记我 确认`

其他内容直接 `@` 机器人进行聊天。

如果第一个词没有精确命中注册功能，消息才作为普通聊天交给模型；模型仍可通过
Tool Calling 自行判断是否需要天气、新闻、联网搜索、新闻详情、历史事件、提醒或
群成员、群聊记录工具，但这属于自然语言兜底，不是稳定调用入口。路由层不会再根据
“天气”等零散关键词猜测意图或维护特殊语句黑名单。

机器人会在两个白名单群里把普通文字消息保存在本机
`data/group_tools.db`，用于 `/总结`。该数据库不会提交到 Git，两个群的数据相互
隔离，每个群最多保留最近 5000 条文字消息。超级用户可以使用
`/清空群聊记录 确认` 删除本群用于总结的记录；该命令不会清除 LLM 短期上下文。
提醒也保存在同一数据库中，机器人重启后仍然有效，但只有机器人和 LLOneBot 在线
时才能准时发送。

提醒属于创建它的 QQ 用户，并按群隔离。其他群友不能查看或取消该提醒；无论使用
`/取消提醒 编号` 还是对机器人说“取消提醒 编号”，都必须由创建者本人操作。机器人
发送提醒时也只会 `@` 创建者。若以后需要全群共享的活动提醒，应另设独立的群提醒
功能，不与个人提醒共用权限。

发送 B 站视频链接、`b23.tv` 短链接或 BV 号时，机器人会自动回复视频标题、UP 主、
时长、播放量、简介和规范链接。

## 群友长期记忆

短期对话重启后清空；群友身份和经过确认的长期记忆保存在本地
`data/bot_memory.db`，该文件不会提交到 Git。长期记忆按群隔离，不会自动从普通
聊天中提取。

项目已创建本地 `data/people.yaml`。参考 `data/people.example.yaml`，为每个真人
设置内部 ID、名称、别名和一个或多个 QQ 号：

```yaml
people:
  zhangsan:
    name: 张三
    qq_ids:
      - "111111111"
      - "222222222"
    aliases:
      - 老张
```

`data/people.yaml` 包含私人账号映射，也不会提交到 Git。修改映射后重启机器人即可
同步；原先由单个 QQ 创建的记忆会迁移到统一身份。

超级用户可使用：

- `/记住 @群友 内容`
- `/查看记忆 @群友`
- `/删除记忆 编号`

群友可用 `/我的记忆` 查看当前群可用的长期记忆，使用 `/忘记我 确认` 删除自己的
全部长期记忆。身份与 QQ 绑定不会随之删除。

## 底层社区插件

天气、运势和新闻由经过 NoneBot 商店检查的社区插件提供，不会调用 DeepSeek，
也不需要 `@` 机器人。对群友统一推荐上面的 `/天气`、`/运势` 和 `/新闻`，
不需要了解各插件原始命令。

天气使用中央气象台实时数据，也可查询支持的区县：

- `/天气 北京`
- `/天气 河北-大城`
- `/支持区县 河北`

新闻默认以纯文本发送，定时推送默认不启用。微博详情需要 Cookie，当前未配置；
微博热搜列表不受影响。“IT之家”的文本源目前会夹带网页标签，“历史上的今天”的
唯一上游目前不稳定，因此没有接入统一菜单。日报插件已缩短失败重试，首选源不可用
时会更快切换备用源。
