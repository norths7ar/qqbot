# qqbot

一个用于私人 QQ 群的对话机器人，也是我的个人实践项目。它可以承接多人聊天、理解文字与图片、查询群友身份，并从历史消息中提取和检索长期记忆。

## 核心设计

- **区分多人对话中的角色**：分别解析发言者、被 @ 的人和引用消息的作者，通过身份配置合并同一人的多个 QQ 账号，避免把不同人的话和经历混在一起。
- **带证据的长期记忆**：从人类消息中异步提取人物资料、偏好和群内事件，记录来源、状态与消息证据。第三方说法默认作为候选，临时事件设置有效期，机器人自己的回复不作为事实来源。
- **按需使用上下文和工具**：共享短期群聊上下文，文字、引用和图片交给同一个多模态模型处理；模型按需查询长期记忆、最近群聊、群成员和联网信息。管理员可通过专用入口维护和删除记忆。

## 技术与链路

Python 3.12 · NoneBot2 · OneBot V11 · SQLite · HTTPX；使用 uv 管理依赖，unittest 和 Ruff 做测试与代码检查。

QQ → LLOneBot → NoneBot2 → 消息与身份解析 → 上下文 / 记忆 / 工具 → OpenAI-compatible 多模态模型 → QQ 回复

项目在 Windows 本地运行。群消息和记忆保存在 SQLite 中，处理链路通过结构化日志关联，便于检查模型调用、工具结果和记忆提取过程。

## 运行概览

使用 `uv sync` 安装依赖，按 [.env.example](.env.example) 配置模型服务、允许响应的群和管理员，再为 LLOneBot 配置 OneBot V11 反向 WebSocket。默认地址为 `ws://127.0.0.1:8080/onebot/v11/ws`。

通过 `scripts/qqbot.ps1` 的 `start`、`stop`、`restart`、`status` 和 `logs` 操作管理进程。脚本默认使用项目内的 `.venv`；联网搜索使用可选的 Tavily 服务。

群友身份配置参考 [people.example.yaml](data/people.example.yaml)。密钥、真实身份配置、聊天数据和日志均不提交到仓库。程序只支持当前数据库格式，不在启动时迁移旧数据。
